# ✍️ Daily Writing Ritual

Beat the blank page. Use this routine to start fast and finish proud.

---

## ☀️ Before You Write (2 min)

- [ ] Open **📊 Writing Dashboard** and read your session notes.
- [ ] Reread the **last paragraph** you wrote (not the whole chapter).
- [ ] Set a timer. Decide: word goal **or** time goal — not both.
- [ ] Silence notifications. One tab. One scene.

---

## ⏱️ While You Write

- Write the scene, not the sentence. Momentum beats polish.
- Stuck on a word? Type `[TK]` and move on. Fix it in editing.
- Don't scroll up to edit. Forward motion only.
- If you hit a wall, ask: *What does my character want right now, and what stops them?*

---

## 🧊 The Pomodoro Sprint

| Round | Action |
| --- | --- |
| 25 min | Write, no stopping |
| 5 min | Stretch, water, no screens |
| Repeat | 3–4 rounds, then a longer break |

---

## 🌙 After You Write (3 min)

- [ ] Log it in **📈 Word Count Log** (even if it's 50 words).
- [ ] Write a one-line note: *where you stopped + what's next.*
- [ ] Stop mid-scene on purpose — it's easier to restart tomorrow.

---

## 🚑 Stuck? Try These Prompts

- Skip ahead and write the scene you're excited about.
- Write the same scene from another character's POV.
- Make something go *wrong* for your protagonist.
- Freewrite for 5 minutes about why the scene feels hard.
- Change location, music, or time of day and try again.

---

## 💬 Mantras

> *"You can't edit a blank page."* — Jodi Picoult

> *"The first draft is just you telling yourself the story."* — Terry Pratchett

> *"Write drunk, edit sober"* — actually: write freely, revise carefully.

# 📐 Story Structure Guide

Reusable frameworks for outlining. Copy any beat sheet into a new project page and fill it in.

---

## 🏛️ Three-Act Structure

**Act I — Setup (≈25%)**
- Hook / opening image
- Inciting incident
- First plot point (door closes behind the hero)

**Act II — Confrontation (≈50%)**
- Rising action & escalating stakes
- Midpoint (false victory or false defeat — everything shifts)
- Pinch points (pressure from the antagonist)
- All is lost / dark night of the soul

**Act III — Resolution (≈25%)**
- Climax
- Falling action
- Resolution / new normal

## 🔢 Seven-Point Story Structure

1. Hook
2. Plot Turn 1
3. Pinch Point 1
4. Midpoint
5. Pinch Point 2
6. Plot Turn 2
7. Resolution

> Tip: Plot the **Resolution first**, then the **Hook** as its mirror image. Build the middle to connect them.

---

## 🧱 Scene Checklist

For every scene, make sure it has:

- [ ] A **goal** (what the POV character wants)
- [ ] **Conflict** (what's in the way)
- [ ] A **turn** (something changes — value shifts +/−)
- [ ] A **hook out** (a reason to keep reading)

---

## 🎭 Character Arc at a Glance

| Stage | Internal state |
| --- | --- |
| Beginning | Lives by a flawed belief / "the Lie" |
| Midpoint | Glimpses the truth, resists it |
| Crisis | Forced to choose: Lie or Truth |
| Climax | Acts on the Truth (or tragically doesn't) |
| End | Transformed (or destroyed) |
